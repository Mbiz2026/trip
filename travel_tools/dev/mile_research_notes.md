## 1. 貯めたポイントを JALマイルに換えるルート

ユーザーはJALカード保有・関空拠点のため **JAL軸** が自然。ANA軸は後述のとおり2026年時点で不利。

| ルート | レート | 条件 | 確度 |
|---|---|---|---|
| **モッピー ドリームキャンペーン** | **実質80%** | 当月に広告利用のみで10,000P獲得 → 1回で12,000Pを交換 → スカイボーナス4,500Pが翌月末に戻る | **公式**(モッピー) |
| 同上 + マイル20%増量期間 | **実質96%** | 上記に加えて増量キャンペーン期間中であること | **公式**(2026/8/1–8/31開催) |
| モッピー 通常時 | 50% | 条件なし | 二次(複数一致) |
| Pontaポイント → JALマイル | 50%(増量時60%) | JMB×Ponta連携。2026年7月に20%増量、2026年3月には25%増量の実績 | **報道**+二次 |
| dポイント → JALマイル | 50%(増量時55%) | 増量キャンペーン時のみ | 二次※ |
| 永久不滅ポイント → JALマイル | 50%(200P=500マイル、増量時60%) | セゾンカード保有 | **公式**(セゾン)+二次 |
| ハピタス等 → ドットマネー → JALマイル | 50%(増量時55%) | | 二次※ |
| **アメックスMR → JALマイル** | **40%**(2,500P=1,000マイル) | メンバーシップ・リワード・プラス加入(年3,300円)。未加入は3,000P=1,000マイル | **報道**(ザイ)+二次一致 |
| アメックスMR → ANAマイル | 100%(1,000P=1,000マイル) | プラス加入 + ANAコース年5,500円(プラチナは無料)。**年40,000マイル上限** | **公式**+報道 |

### モッピー ドリームキャンペーンの正確な仕組み(公式ページより)

- 期間: 月単位で開催(確認したのは 2026年8月1日 0:00 – 8月31日 23:59)
- 条件: 「当月にJALマイルへの交換申請前までに、**広告利用のみで**合計10,000Pを獲得」+「**1回の交換で12,000P**をJALマイルに交換」
- 特典: **スカイボーナス4,500P**を翌月末頃に付与。**お一人様につき毎月1回**
- 計算: 12,000P − 4,500P = **正味7,500Pで6,000マイル → 80%**
- 8月は20%増量が重なり 12,000P → 7,200マイル。正味7,500Pで7,200マイル = **96%**
- **「広告利用のみ」から除外されるもの**(公式に明記): チャレンジボーナス、各種キャンペーン/ボーナスポイント、
  アプリマルチミッション、スタッフ激推し月額サービス、人気定番コンテンツ、モッピーレシ活、モッピーフクモニ、**アンケート**
- 除外条件: 過去90日以内に合計10,000P以上の否認がある人は対象外(二次※)
- ANAブーストキャンペーンとの併用不可(公式)

> ⚠ **要確認ポイント**: 複数の解説記事は「**ゴールド会員であること**」も条件に挙げているが、
> 2026年8月版の公式ページにはランク要件の記載を確認できなかった。**月ごとに条件が変わる**ため、
> マニュアルには「毎回モッピー公式のキャンペーンページで条件を読む」手順を必ず入れること。
> (モッピーのゴールド会員条件 = ランクアップ対象広告で合計10,000P以上が「承認」に反映されること。二次)

### モッピー運用の基礎データ

- ポイント有効期限: **180日**。180日以内にログイン+1P以上の獲得で自動延長(二次・複数一致)
- JALマイルへの交換手数料: **無料**。反映まで**約4週間**(二次・複数一致)
- 通常レート 2P = 1マイル

### 終了済み・使えないルート(発信内容の鮮度チェック用)

| ルート | 状況 | 確度 |
|---|---|---|
| ソラチカルート(LINE→メトロポイント→ANA) | 2019年に封鎖 | 二次(定説) |
| **TOKYUルート**(75%) | **2022年3月31日で閉鎖** | 二次(複数一致) |
| **JQみずほルート**(70%) | みずほマイレージクラブカード/ANAが **2026年1月21日で新規申込終了**。既存保有者のみ継続 | 二次(複数一致) |
| nimocaルート(70%) | 存続。ただし**九州・函館の物理端末での操作が必須** | 二次(複数一致) |
| Vポイントルート(60%) | 存続。三井住友ANAカードが必要。ANA陸マイラーの現行本命 | 二次(複数一致) |

→ **ANA側は2026年時点で「特殊カード必須 or 現地に行かないと交換できない」状態**。
JALの80%(モッピー)の方が、条件がシンプルで再現性が高い。**JAL軸を推す根拠。**

## 2. 決済カードでのマイル獲得(ユーザー保有カードの精査)

| カード | JALマイル還元 | 追加コスト | 注意 |
|---|---|---|---|
| **セゾンプラチナ + SAISON MILE CLUB** | **1.125%** | SMC 年5,500円 | 1,000円=10マイル + 2,000円=1永久不滅P(=2.5マイル相当) |
| JALカード + ショッピングマイル・プレミアム | 1.0% / **特約店 2.0%** | SMP 年4,950円 | 特約店は全国52,000店以上 |
| JALカード → JMB WAONチャージ + WAON決済 | 最大 **1.5%** | JMB WAON発行 | **対象カード限定**(下記) |
| アメックス(MR) → JAL | 0.4% | プラス 年3,300円 | **JAL狙いでは不利** |
| アメックス(MR) → ANA | 1.0%(年4万マイル上限) | プラス+ANAコース 年5,500円 | ANA用としては優秀 |

### SAISON MILE CLUB(公式で確認)

- サービス年会費: プラチナ **5,500円** / ゴールド 9,900円 / プラチナビジネス **5,500円**
- 積算: カード利用**1,000円につき10マイル** + 優遇永久不滅ポイント**2,000円につき1P**(200P = 500マイル)
- **年間移行上限 150,000マイル**。上限到達なら翌年のサービス年会費無料
- セゾンプラチナ・アメックス(個人)の SMC は **2024年7月の更新・登録分から有料化**(以前は無料)。**報道**(ザイ 2024-04-10)

### ⚠ セゾンの重要な改悪(公式で確認・マニュアル必須項目)

1. **2025年11月11日以降、電子マネー/プリペイドカードチャージは永久不滅ポイントもSAISON MILE CLUBのマイルも付与対象外**
   (楽天Edy・nanacoは以前から対象外。Suica/PASMO/ICOCA/PayPay/au PAY/WAON/Kyash/バンドルカード/ANA Pay/**JAL Pay** 等が対象)
2. **税金・自治体の水道料金は 2,000円につき10マイル(=0.5%)** に減額(2024年1月11日から)。**ふるさと納税は対象外**
3. 1,000円未満の利用・各種手数料は永久不滅ポイント対象外

→ **国税のクレカ納付手数料は約0.836%** なので、**セゾンプラチナで税金を払うと赤字**(0.5% − 0.836%)。
   これは「税金をカードで払ってマイルを貯めよう」という発信を否定する材料。

### JALカード側

- ショッピングマイル・プレミアム 年4,950円(2023年6月に3,300円→4,950円へ改定)。損益分岐点は年約49.5万円決済
- **特約店で 100円=2マイル**。イオン・ファミリーマート・ウエルシア・大丸松坂屋・無印良品・ユニクロ・ロイヤルホスト・ENEOS など
- ツアープレミアム 年2,200円 → 割引運賃でも区間マイル100%(**乗る人向け**。陸で貯める用途では不要)
- **JMB WAONクレジットチャージ**: 2026年時点で継続中。チャージ時と決済時の二重取り。
  対象は JAL・JCB / JAL・Visa / JAL・Mastercard / JALカードTOKYU POINT ClubQ。
  **JALダイナース・JALカードSuica・JALカードOPクレジット・JAL アメリカン・エキスプレスは対象外**(二次・複数一致)

### JALマイレージパーク(JALマイレージモール)経由

- 楽天市場は300円=1マイル、獲得マイル100ごとに1 LSP(Life Statusポイント)(二次)
- JALマイレージパーク経由 + JALカード決済で二重取り
- **Amazonは2026年6月からシステムメンテナンスで積算休止・再開未定**(二次)→ 「Amazonも貯まる」という発信は現在誤り

## 3. マイルの寿命

- JALマイルの有効期限は **36ヶ月**
- **2025年1月以降に貯まるマイル**は、JMB elite / JMB elite plus / JGC Three Star なら **60ヶ月**、
  **JGC Four Star 以上は無期限**(JAL Life Statusプログラム1周年の施策)。**報道**(TRAICY 2024-12-19 / Aviation Wire)
- 2024年以前に貯めたマイルは36ヶ月のまま
- JGC入会条件は2024年1月から「生涯累計 Life Statusポイント1,500以上 + JGC JALカード(CLUB-A以上)」に変更。
  国内線は1区間5 LSP → フライトだけだと300回必要。**乗らない人には現実的でない**(二次・複数一致)

→ ひとり旅・陸で貯める前提なら、**マイルは36ヶ月の時計付き**。貯めっぱなしにせず使い切る設計が必要。

### 「保険相談案件」の扱いについて(倫理的な注記)

複数の解説記事が「担当のFPにはポイント目的だと伏せるべき」と書いている。
これは相手を欺く助言なので、**マニュアルではその形では推奨しない**。
「実際に保険を見直す意思があるときだけ、ついでにポイントサイトを経由する」という形に限定して紹介する。

## 6. リスク・落とし穴

| リスク | 内容 | 確度 |
|---|---|---|
| **多重申込による審査落ち** | CICの申込情報は**照会日から6ヶ月間**保持。短期間の大量申込は「申込ブラック」として警戒される。**年5〜6枚が目安**という個人の見解あり | 二次(複数一致) |
| **税金** | ポイントサイトの広告利用ポイントは一般に**雑所得**。給与所得者は給与以外の所得が**年20万円超**で確定申告が必要。カードの入会特典は**一時所得**(特別控除50万円、実質90万円超で申告)。課税タイミングは原則「使った時」 | 二次(税理士系サイト・会計ソフト各社が一致)※最終判断は税務署/税理士へ |
| **マイル失効** | JALマイル36ヶ月(ステータス次第で60ヶ月/無期限)。**貯めてから使うまでの設計が必要** | 報道 |
| **ポイント失効** | モッピーは180日。ログイン+獲得で延長 | 二次 |
| **案件の否認** | 経由忘れ・Cookie・条件未達で無効。過去90日で10,000P以上の否認があるとドリームキャンペーン対象外 | 二次※ |

| **制度改定の速さ** | 2025-06 JALチャート改定、2025-10 ふるさと納税ポイント禁止、2025-11 セゾン電子マネー改悪、2026-01 みずほルート終了、2026-02〜04 Kyash改悪 | 各項参照 |

## 7. 年間シミュレーション(ユーザー条件での試算)

**前提**: 会社員(給与のみ) / ひとり旅 / 数万円の入金が必要な案件はNG / クレカ発行はOK /
アメックス系・JALカード・セゾンプラチナを保有 / 関空発

### 収入源ごとの現実的レンジ

| 源泉 | 控えめ | 標準 | 上振れ | 前提 |
|---|---|---|---|---|
| モッピー ドリームキャンペーン | 36,000 | 48,000 | 60,000 | 10,000P/月を達成できた月数 = 6 / 8 / 10ヶ月。1回=正味7,500P→6,000マイル |
| カード決済(セゾンプラチナ1.125%) | 13,500 | 20,000 | 27,000 | 月10 / 15 / 20万円決済 |
| 特約店・JMB WAON・モール経由の上乗せ | 2,000 | 5,000 | 8,000 | 日常の一部を特約店に寄せる |
| Ponta/dポイント増量CP・その他 | 2,000 | 5,000 | 8,000 | 年2〜4回の増量期を拾う |
| **合計** | **約53,500** | **約78,000** | **約103,000** | |

### 旅行回数への換算(ひとり・往復エコノミー・基本マイル)

JAL国際線の基本マイル(往復Y): ソウル15,000 / 台北・香港20,000 / バンコク35,000 / ロンドン・パリ54,000 / NY・LA・SF 54,000

| 年間マイル | 近距離中心(ソウル・台北・香港) | 東南アジアを混ぜる | 欧米を入れる |
|---|---|---|---|
| 約55,000 | **年3回** | 年2回 | 年1回 |
| 約78,000 | **年4回** | 年3回 | 年1回+近距離1回 |
| 約103,000 | **年5〜6回** | 年3〜4回 | 年1回+近距離3回 |

### 結論

- **「3ヶ月に1回(年4回)」は、行き先をソウル・台北・香港などの近距離アジア中心にすれば十分に射程内。**
- 東南アジア(バンコク等)を毎回にすると年2〜3回が上限。
- 欧米を年1回入れると、残りは近距離1〜2回。
- 最大のボトルネックは **「モッピーで広告利用のみ月10,000Pを何ヶ月クリアできるか」**。
  ここが年6ヶ月なら控えめ、年10ヶ月なら上振れになる。
- 燃油サーチャージ・空港税は別途必要(JAL便は燃油あり。近距離でも往復数千円〜)。
  燃油ゼロの会社を選ぶワザは既存アプリ `mile_compass.html` の「マイル術」タブに整理済み。

## 9. マニュアル本体を作るときの申し送り

1. **数字には必ず確認日を付ける**(CLAUDE.md ルール3)。特に燃油・チャート・キャンペーンは2ヶ月で変わる
2. **JavaScriptなしで全情報が読めること**(CLAUDE.md ルール1)。計算機はJS、情報はCSSのみ
3. **月次ルーティンを主役にする** — 「毎月やること」「四半期ごと」「年1回」の3レイヤー
4. **公式リンクのみ**を載せる。代行サイト・スクールへの誘導は禁止(CLAUDE.md ルール3)
5. 既存の `mile_compass.html`(使う側)と重複させず、**貯める側に特化**して相互リンクする
6. 「ゴールド会員要否」「キャンペーン期間」は毎月変わるので、**アプリに数字を焼き込まず「公式で確認する手順」を書く**
