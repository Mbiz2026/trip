## 3. 入国要件(外務省 安全対策基礎データ)

### カンボジア — **ビザ必須**
- 「カンボジアに入国するためには査証が必要です」
- 取得法: 在外公館 / アライバルビザ(主要空港・陸上国境) / **e-Visa https://www.evisa.gov.kh**(観光T・商用E)
- 観光査証(T): **最長30日**、就労不可。**残存6ヶ月以上**必要。数次査証も可
- **オーバーステイ 1日US$10の罰金**、支払いが出国の条件
- e-visaは**更新不可**。延長相談はプノンペン出入国管理総局(TEL 089-282-838)
- **入国・税関・検疫はオンライン提出必須**: **www.arrival.gov.kh** / アプリ「Cambodia e-Arrival(CeA)」、**到着日の7日前から**
- 外貨: 1万米ドル相当以上の持込は申告。持出は中央銀行等の事前許可
- パスポート紛失時: **出国査証(Exit Visa)が必要。プノンペンの入管本部でのみ申請可、1〜3日**(土日祝不可)
- 駐日カンボジア大使館 03-5412-8521
- ⚠️ **cambodianembassy.jp は現在まったく別のFX関連サイトになっている(大使館ではない)。案内しないこと。**

### タイ
- 日本国旅券は観光目的で**ビザなし60日**
- **TDAC**(2025年5月1日導入): 全非タイ国籍者、陸海空問わず。**到着の3日前(到着日含む)から**登録可。公式 **https://tdac.immigration.go.th/**
- 「最終目的地がタイ以外で入国審査を受けずに空港トランジットする場合はTDAC不要。ただし別切り航空券等で一度入国し荷物をピックアップする場合は必要」
- パスポートのメモ書き・記念スタンプ・シール・破れ・顔写真汚損で**出入国拒否の事例あり**
- 入国印の押し忘れトラブルあり。受け取ったらその場で確認
- First Port Arrival 原則
- 2025年犯罪統計: 殺人(未遂含)3,981件 / 強制性交1,875件 / 盗難34,961件 / 銃器爆発物48,374人検挙 / 薬物418,104人検挙
- 2025年の日本人被害:「お金を見せてほしい」と声を掛けられ現金・クレカを抜き取られる窃盗が**多発**
- 不敬罪: 王室侮辱で**3年以上15年以下の禁錮**のおそれ。仏像の国外持出禁止。僧侶は女性に触れない。頭部タブー・足裏を向けない

### ベトナム
- **45日以内はビザ免除**。条件: 入国時点で**残存6ヶ月以上**、帰国またはトランジット出国のチケット保持、入国禁止措置を受けていないこと

- **電子たばこ・加熱式たばこ: 2025年1月1日から国内使用が罰金対象の可能性、海外からの持込は使用より重い罰金の可能性**
- 免税範囲: 酒22度以上1.5L / 22度未満2L / ビール等3L、紙巻200本、葉巻20本、葉たばこ250g、金300g

- 2025年犯罪: 47,713件・逮捕74,426人。**当地発着の機内で収納棚から現金・クレカを窃取される被害が増加**
- ひったくり多発地区: ハノイ=キンマー・リンラン / ホーチミン=レタントン・タイバンルン。賭博は原則犯罪

## 4. 医療・健康(外務省)

- カンボジア:「一定の治療水準を満たす医療施設は**首都プノンペンとシェムリアップにしかなく**、手術が必要な場合には日本や周辺国に**緊急移送**されることがあります」
- 「**無保険かつ支払い能力が無いと判断された場合には、治療を拒否されることがあります**」→ キャッシュレス対応の保険を推奨
- カンボジア全土で細菌性胃腸炎・A型肝炎・ジアルジア症などの経口感染症が多発。特に生水・果物・生野菜・魚介類
- **デング熱は都市部でも流行**。日本脳炎・マラリアの危険地域もある
- **狂犬病の死者あり。犬だけでなく様々な哺乳類が保菌の可能性 → 哺乳類に触れない**
- 予防接種(A型肝炎・B型肝炎・日本脳炎・腸チフス・狂犬病・デング熱)は「**遅くとも出発1ヵ月以上前**に相談」→ 8/26時点で28日なので間に合わないものがある
