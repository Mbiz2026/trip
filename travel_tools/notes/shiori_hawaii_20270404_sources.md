## 3. 入国要件(外務省 米国 2026/5/14更新)

- **ESTA**: 90日以内の観光はビザ免除プログラム。条件=**IC旅券**、特定地域への渡航歴なし、往復航空券、ESTA承認。
- **申請料 40.27ドル**(外務省の記載)。政策トラッカー(二次)によると2025年の法改正による物価連動で$40→$40.27。**2027年1月に再改定の可能性**(二次情報)。
- 72時間以上前の申請を推奨。未承認だと**搭乗拒否**。承認後**2年間有効**、旅券を更新したら再申請。
- 代行サイトで本来の数倍の手数料を請求された事例(外務省)。公式は **https://esta.cbp.dhs.gov/** のみ。
- 子どもも1人ずつ必要(VWP加盟国民は全員取得が必要。CBP発表ではGroup IDで最大50件をまとめて支払い可)。
- SNS項目の必須化: 提案段階。在フランス米国大使館のファクトシートでは2026/2/9にパブコメ終了・**未発効**。
- **旅券の残存**: 原則「滞在期間+6か月」だが、**日本国籍者は米国出国予定日まで有効なら可**。残存90日未満だと滞在許可がその期間に短縮 → 早めの更新推奨。
- 生体情報: **14〜79歳**の渡航者から指紋・顔画像を採取(一部例外あり)。
- 入国審査で聞かれうること(外務省ハワイ): 渡航目的、居住地、宿泊先、滞在期間、帰国便。
- 税関: 機内配布の**税関申告書(6059B)**に記入して提出。申告無しでも提出が必要。非居住者の免税: たばこ200本または葉巻100本(21歳以上)、酒1L(21歳以上)、贈答品100ドル相当。現金等1万ドル超はFinCEN 105で申告(家族の合計で申告書に記載)。
- 持込禁止・制限: 医薬用麻薬を含む医薬品、規制薬物、酒類、**果物・野菜・植物・土壌・精肉・肉製品**、動物製品 など。
- 未成年が片親や他人と渡航する場合は出生証明や同意書の携行が推奨(両親とも同行なら不要)。
- TSA: 預け荷物は施錠しないかTSAロック。施錠できないと切断されることがある。
- Mobile Passport Control: 米国市民・永住者・一部カナダ人・**再訪のESTA承認者**が対象(公式アプリ説明)。ホノルルで使えるかは未確認。
- ハワイ州の農産物申告書: 機内で配布、記入して提出。検査官は手荷物受取エリアにいる(ホノルル空港公式)。一部の便ではデジタル版あり(Akamai Arrival)。

## 4. 医療・健康(外務省ハワイ・米国)

- 医療水準は問題なし、日本語のわかる医師も多い。**治療費・入院費は極めて高額、救急車も有料**。
- **ICU 1日10,000ドル以上の例も少なくない**。救急車は状況により数百ドル〜千ドル超。入院・緊急手術で**数千万円**を請求された例。
- **クレカ付帯保険は限度額が数百万円程度で重篤時に不足**しうる。保険情報を日本の家族に伝えておく。
- 911で救急車。搬送先の病院は指定不可。ERは重症優先。軽症は Urgent Care / Walk-in Clinic を推奨(外務省米国)。
- ハワイに特筆すべき風土病なし。過去にデング熱(蚊)、レプトスピラ症(ネズミ・マングース等)、広東住血線虫症(ネズミ・ナメクジ等)。
- 米国の一部地域で**麻しん**の発生報告。罹患歴・接種歴が無い/不明なら予防接種を検討。
- 衛生状態は良好。
- 空港の診療所: **T2 1階・日本庭園の隣**、有料、808-836-6643。空港内の館内電話から **711**(ホノルル空港公式)。

- タクシーの除外: 「業務用車両は対象外」とする旅行サイトはあるが、**州法原文は capitol.hawaii.gov が403で未確認**。配車アプリは除外の根拠なし。罰則額も未確認(古い記事で$100〜500+講習)。
- 古い資料(2007年施行)は「4〜7歳」。現在の公式は「10歳未満」。

### 子どもに関する決まり(外務省ハワイ・米国)
- **無人の車内に子どもを放置することは州が禁止**(運転者・大人の同乗者)
- 米国小児科学会は12歳くらいまで大人の監督を推奨。単独留守番で被害があれば親が児童虐待で逮捕の可能性
- **16歳未満は保護者同行なしで22:00〜4:00外出不可**(ハワイ州)
- 体罰・人前で大声で叱る=虐待とみなされうる。服・靴を着せず外を歩かせる、食事を与えない等もネグレクトとして通報例

### 交通ルール(外務省ハワイ)
- 横断歩道以外の横断、**横断中に電子機器の画面を見る**行為は違反。シートベルトは同乗者も。
- 2025年の交通死亡事故は前年比約140%。日本の約4.5倍の発生率。死者の約3割がモペッド。
- 旅行者は入国後1年以内なら日本の免許で運転可(パスポート携行)。英語表記が無いため無免許扱いの例 → **国際運転免許証を強く推奨**。

## 10. その他

### 電源
120V・60Hz、Aタイプ(Bタイプも)。日本と同じ形で変換プラグは基本不要。**二次情報**(家電メーカー案内等が一致。IEC公式は403で未取得)。熱器具は注意、「INPUT 100-240V」表示なら可。

### お金・税
- ハワイの一般消費税(GET): 州4%+オアフ郡0.5%=4.5%、上乗せ上限 **4.712%**(二次情報・Stripe解説。4.5÷0.955で整合)
- 州宿泊税(TAT): **2026/1/1に10.25%→11%**(Act 96、二次情報)。郡3%とGETを合わせて宿泊代の約18〜19%(二次情報)
- チップ: 金額の公式基準なし。Service Charge / Gratuity が含まれていれば二重払いしない。

### 喫煙(ホノルル空港公式)
- 空港は「キャビンから歩道の縁まで」州法で禁煙。喫煙可:
  - **T2 1F**: Diamond Head Group Tour Area(屋根の無い所)
  - **T2 2F**: チケットロビー前の道路中央分離帯
  - **T2駐車場5F**(出入口・エレベーター/階段から20フィート以上)、屋根の無い駐車場
  - T1 1F: Pre-Arranged 1の隣(T1と国際線到着棟の間)、T1駐車場7F
  - すべて出入口・窓・換気口から20フィート(約6m)以上。違反は罰金
- 制限エリア内(出国後)の喫煙所は公式ページに記載なし → **無いと考えて案内する**
- 米国: 屋内(飲食店の屋外席を含む)は禁煙(外務省)
- 州立公園(ダイヤモンドヘッド含む): 2015/7/1から**電子たばこ含め全面禁煙**、罰金初回$100/2回目$200/以降$500(DLNR発表を報道経由で確認)
- ホノルル市のビーチ・公園: 紙巻きは禁煙(2014年〜報道)。電子たばこを含むかは未確認
- 購入・所持の年齢: 21歳(2015年州法、報道)
- **加熱式たばこ(IQOS等)の米国持込の扱い: 公式情報が見つからず未確認**。免税はたばこ200本(21歳以上・外務省)

### 日本への持ち帰り(植物防疫所・動物検疫所)
- ハワイから: かんきつ類・キウイ・さくらんぼ・バナナ・**パパイヤ**・グアバ・**マンゴウ**・りんご・かぼちゃ・トマト → **持ち込めない**
- パインアップル・ココヤシ・アスパラガス・乾燥豆・精米・ラン/ドラセナの切り花 → 検査証明書+入国時検査
- **マカダミアナッツ(乾燥) → 入国時の検査が必要**
- マッシュルーム・緑茶/紅茶 → 検査なしで可
- プルメリア苗・穂木 → 2017/5/24以降、追記つき検査証明書が無いと一切不可
- 土・土の付いた植物 → 全地域不可
- **ビーフジャーキーなど牛肉製品: アメリカ(ハワイ・グアム・サイパン含む)産は輸入停止**。少量・個人用・免税店購入・真空パックでも不可
- 一覧の更新日: 2021/7/5(植物防疫所)。【要再確認】

### お土産
- コナコーヒー: 2001年の州法で、コナ産10%で「Kona Blend」と表示可。2024年に表示要件を引き上げる法案(HB2298、51%など)が可決との報道。知事署名・施行時期は未確認(二次情報)。
